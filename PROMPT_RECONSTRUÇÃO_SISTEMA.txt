Atue simultaneamente como:

* Engenheiro full-stack.
* Especialista em Next.js, React e TypeScript.
* Especialista em PostgreSQL e Supabase.
* Especialista em UX/UI para sistemas administrativos.
* Especialista em migração de sistemas Google Sheets/Google Apps Script para aplicações web.
* Engenheiro de segurança de aplicações.
* Engenheiro de testes automatizados.
* Especialista em processamento de arquivos Excel.
* Especialista em arquitetura de sistemas administrativos e CRUDs complexos.

Você deverá reconstruir o sistema existente chamado:

**Gestão de Apostilas - Microlins Potirendaba**

A aplicação atual funciona com:

**Google Sheets + Google Apps Script + Web App HTML**

A nova aplicação deverá funcionar como:

**Aplicação Web + Next.js + TypeScript + Supabase + PostgreSQL + GitHub + Vercel**

O Google Sheets deverá deixar de ser o banco de dados e deixar de ser o núcleo operacional do sistema.

# 1. OBJETIVO PRINCIPAL

Criar uma nova versão profissional, moderna, responsiva e independente do Google Sheets do sistema:

**Gestão de Apostilas - Microlins Potirendaba**

A aplicação deverá preservar as regras de negócio já existentes, mas substituir a infraestrutura baseada em planilhas por uma aplicação web com banco de dados relacional.

O resultado deverá ser uma aplicação acessível por navegador, com URL pública de produção, sendo o GitHub o repositório oficial do código e a Vercel o ambiente recomendado para publicação da aplicação web.

Não transforme o projeto em uma simples página estática.

O sistema precisa ser uma aplicação real, persistente, segura e preparada para evolução.


